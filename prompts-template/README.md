## 💡 Como Usar

1. Abra o arquivo do prompt desejado.
2. Copie o conteúdo para a sua ferramenta de IA (Claude Code, Google Antigravity ou Cursor).
3. Substitua os placeholders padronizados (ex: `[NOME_DA_MARCA]`, `[URL_DO_SITE]`, `[OBJETIVO]`).
4. Execute e acompanhe a entrega estruturada.
