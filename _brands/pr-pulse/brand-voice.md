# Brand Voice — PR Pulse

## Sobre a marca
PR Pulse é um ERP para agências de PR (Relações Públicas). Software de gestão operacional focado nas necessidades específicas de agências: clientes, pautas, clippings, relatórios, equipe.

## Tom e voz
- **Do setor** — fala a língua de quem trabalha em agência de PR
- **Prático e organizado** — resolve dores reais de gestão
- **Profissional mas não frio** — o setor de PR é relacional
- **Autoridade** — conhece o mercado de comunicação profundamente

## Linguagem
- Use: "pauta", "clipping", "media coverage", "assessoria", "press release", "relatório de mídia", "KPI de PR", "share of voice"
- Evite: jargão genérico de SaaS sem contexto de PR
- Tom: colegas de setor, não vendedor de software

## O que NÃO comunicar
- Que vai substituir a criatividade ou o relacionamento humano das agências
- Complexidade técnica desnecessária
- Linguagem de TI para um público de comunicação

## Exemplos de voz
✅ "Menos planilha, mais pauta. PR Pulse cuida da operação para você cuidar dos clientes."
✅ "Relatório de clipping pronto em minutos. Seus clientes vão amar."
❌ "Nossa solução de gestão otimiza workflows operacionais para agências"
❌ "Sistema ERP com módulos customizáveis para o setor de PR"
