# Style Guide — PR Pulse

## Identidade Visual (referência)
- Cores: azul, branco, detalhes em laranja ou verde (modernidade + confiança)
- Estética de dashboard, dados organizados, profissional

## Tom por canal
| Canal | Tom |
|-------|-----|
| LinkedIn | Autoridade no setor, dado + insight |
| Email | Direto, funcional, valor claro |
| Blog | Guia prático, referência para o setor |
| Demo/Vídeo | Claro, mostra a dor e a solução |
| Instagram | Mais leve, bastidores de agência, inspiração |

## Formatos que funcionam
- Carrossel "X erros de gestão em agências de PR"
- Post de dado + insight sobre o mercado
- Template gratuito como lead magnet
- Vídeo demo de 3-5 minutos
