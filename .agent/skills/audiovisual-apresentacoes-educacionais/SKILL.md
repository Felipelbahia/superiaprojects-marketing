# Apresentações Educacionais

Guia para montar slides que ensinam: o que colocar em cada slide, como reduzir o esforço mental de quem assiste e como conferir o resultado antes de apresentar. Os arquivos de referência vieram do `audiovisual-pitch-deck` (2026-10-20), onde estavam fora do assunto.

## Quando usar

- Criar slides de aula, treinamento, workshop ou webinar.
- Reformar uma apresentação que está um "muro de texto".
- Conferir uma apresentação pronta contra uma lista de qualidade e acessibilidade.
- Planejar o roteiro de uma aula em eventos de instrução (abertura, objetivo, prática, feedback, fechamento).

## Quando NÃO usar

- Pitch de investidor, deck de venda ou one-pager: use [audiovisual-pitch-deck](../audiovisual-pitch-deck/SKILL.md).
- Slides de código ou palestra técnica em Markdown: use [audiovisual-slidev](../audiovisual-slidev/SKILL.md).
- Roteiro falado de videoaula ou vídeo curto: use os workflows `/copy-roteiro-de-video` e `/copy-hook-de-video`.
- Gerar o arquivo `.pptx`: o método está em [pptx](../audiovisual-pitch-deck/references/pptx.md) e [html2pptx](../audiovisual-pitch-deck/references/html2pptx.md); aqui você decide o conteúdo e o desenho, lá a construção do arquivo.

## Como usar

1. Leia [educational-presentation.md](references/educational-presentation.md) (guia principal) e escolha o objetivo de aprendizagem de cada bloco.
2. Monte os slides com os modelos de [slide-templates](../audiovisual-pitch-deck/references/slide-templates.md).
3. Compare com [before-after.md](references/before-after.md) para evitar os erros típicos.
4. Antes de apresentar, passe pela [validation.md](references/validation.md); para um lembrete de 30 segundos, use [quick-reference.md](references/quick-reference.md).
