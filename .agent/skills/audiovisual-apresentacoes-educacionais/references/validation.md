# Validation Checklist - Présentation Éducative

## Introduction

Cette checklist est votre dernière étape avant de présenter. Utilisez-la pour valider que chaque aspect de votre présentation respecte les principes de design éducatif et d'accessibilité.

**Notation** :
- ✅ Oui = 1 point
- ⚠️ Partiellement = 0.5 point
- ❌ Non = 0 point

**Scores** :
- 95-100% = Excellence (🏆 Prêt à présenter)
- 85-94% = Très bien (🎯 Quelques ajustements mineurs)
- 70-84% = Acceptable (⚠️ Amélioration recommandée)
- <70% = À retravailler (🔴 Révisions nécessaires)

## INTERPRÉTATION DU SCORE

### 🏆 165-174 points (95-100%) - EXCELLENCE
**Félicitations !** Votre présentation est exemplaire.
- Applique rigoureusement les principes cognitifs
- Design professionnel et accessible
- Prête à présenter sans modification

### 🎯 148-164 points (85-94%) - TRÈS BIEN
**Excellent travail !** Quelques ajustements mineurs recommandés.
- Solide dans la plupart des domaines
- Quelques détails à peaufiner
- Révision légère suggérée avant présentation

### ⚠️ 122-147 points (70-84%) - ACCEPTABLE
**Bon départ**, mais améliorations nécessaires.
- Bases solides mais lacunes identifiées
- Focus sur sections <80%
- Révision recommandée avant présentation

### 🔴 <122 points (<70%) - À RETRAVAILLER
**Révisions substantielles nécessaires**
- Plusieurs principes fondamentaux non respectés
- Risque de charge cognitive élevée
- Revoir le skill complet avant de continuer

## PLAN D'ACTION SELON SCORE

### Si Score < 70% : Révision Complète
1. Relire SKILL.md Section 1 (Cognitive Foundation)
2. Relire exemples before/after
3. Appliquer checklist section par section
4. Tester avec un collègue
5. Re-valider avec cette checklist

### Si Score 70-84% : Focus Ciblé
1. Identifier sections <70%
2. Consulter SKILL.md pour ces sections
3. Appliquer corrections spécifiques
4. Re-valider ces sections uniquement

### Si Score 85-94% : Polish Final
1. Identifier points 0.5 et 0
2. Micro-ajustements
3. Contrast checker final
4. Test technique

### Si Score ≥95% : Prêt !
1. Faire backup du fichier
2. Test final sur équipement réel
3. Préparer speaker notes
4. Go présenter ! 🎉

## OUTILS DE VALIDATION RECOMMANDÉS

### Accessibilité
- **PowerPoint** : File > Info > Check for Issues > Check Accessibility
- **Google Slides** : Grackle Slides add-on
- **Contraste** : WebAIM Contrast Checker (webaim.org/resources/contrastchecker/)

### Design
- **Grilles** : Activer guides dans View menu
- **Alignment** : Utiliser les outils d'alignement natifs
- **Fonts** : Font size checker dans settings

### Technique
- **Preview** : Mode présentation complet
- **Export** : Tester PDF export (si nécessaire)
- **Timing** : Timer pour estimer durée réelle
