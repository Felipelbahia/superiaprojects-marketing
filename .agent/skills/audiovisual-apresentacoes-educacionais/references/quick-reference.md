# Quick Reference Guide - Présentation Éducative

## 🚀 Démarrage Ultra-Rapide

### Les 3 Règles d'Or
1. **Visuel + Narration** (jamais texte + narration)
2. **1 Slide = 1 Idée** (chunking obligatoire)
3. **Design = Outil d'Apprentissage** (pas décoration)

---

## ⚡ Checklist 30 Secondes (Par Slide)

```
❓ Ce slide a-t-il UN seul message clair ?
❓ Y a-t-il une image/visuel pertinent ?
❓ Le texte fait-il moins de 10 mots ?
❓ La police est-elle ≥ 24pt ?
❓ Le contraste est-il ≥ 4.5:1 ?
❓ Est-ce aligné sur une grille ?
```

**6 × ✅ = Slide validé**
**<5 × ✅ = À retravailler**

## 🎨 C.R.A.P. en 4 Questions

```
C - Contraste    → Y a-t-il une hiérarchie ÉVIDENTE ?
R - Répétition   → Même style partout ?
A - Alignement   → Tout sur une grille invisible ?
P - Proximité    → Éléments liés = collés ensemble ?
```

## 🔤 Typographie - Règles Express

```
✅ DO                          ❌ DON'T
────────────────────────────────────────────
Sans-serif (Arial, Calibri)   Times New Roman
≥ 24pt (corps)                 < 20pt
≥ 36pt (titres)               Centré (corps texte)
Aligné gauche                  ALL CAPS
Bold pour emphase              Souligné (= lien)
Max 2 fonts                    5+ fonts
```

---

## 🌈 Couleurs - Règle 60-30-10

```
60% → Fond (blanc, gris clair)
30% → Secondaire (structure)
10% → Accent (highlight)

Contraste minimum : 4.5:1
Outil : webaim.org/contrastchecker
```

---

## 📐 Formules Magiques

### Taille Police Idéale
```
Distance audience (mètres) / 7.5 = Taille min (pt)

Ex: Audience à 7.5m → 7.5/7.5 = 1" ≈ 30pt minimum
```

### Durée Slide
```
1 slide simple = 30-60 secondes
1 slide complexe = 2-3 minutes (avec progressive disclosure)

Présentation 15 min = 15-20 slides MAX
```

### Charge Cognitive
```
Intrinsic Load (contenu) + Extraneous Load (design) = Total Load

But : Minimiser Extraneous pour maximiser Germane (apprentissage)
```

## 🎬 Progressive Disclosure - Mode d'Emploi

### PowerPoint
```
1. Select text/object
2. Animations tab
3. "Appear" or "Fade"
4. Effect Options > "By Paragraph"
5. Trigger : "On Click"
```

### Google Slides
```
1. Select text/object
2. Insert > Animation
3. "Fade In"
4. Trigger : "On Click"
5. ✅ "By paragraph"
```

**Quand ?**
- Listes ≥ 3 items
- Diagrammes complexes
- Processus séquentiels

## ♿ Accessibilité - 5 Must-Have

```
1. Contraste ≥ 4.5:1 (texte normal)
2. Contraste ≥ 3:1 (texte large 18pt+)
3. Alt text sur TOUTES images
4. Police ≥ 24pt
5. Pas de couleur seule pour signifier (ajouter forme/texte)
```

## 📊 Choix de Graphique - Décision Rapide

```
Comparer catégories        → Bar chart (Y-axis à 0)
Tendance dans le temps     → Line graph (max 4 lignes)
Parties d'un tout          → Pie chart (max 5 parts) OU Stacked bar
Corrélation 2 variables    → Scatter plot
Hiérarchie/Organisation    → Tree diagram / Flowchart
```

## 🧠 Mémo Charge Cognitive

```
🟢 GERMANE LOAD (BON)
   → Effort d'apprentissage réel
   → Intégration des connaissances
   → Construction de schémas mentaux
   ✅ À MAXIMISER

🟡 INTRINSIC LOAD (NEUTRE)
   → Difficulté inhérente du sujet
   → Géré par chunking
   → Scaffolding temporaire
   ⚖️ À GÉRER

🔴 EXTRANEOUS LOAD (MAUVAIS)
   → Effort pour comprendre le design
   → Distractions visuelles
   → Redondance texte/narration
   ❌ À MINIMISER
```

## 📏 Espacement & Marges

```
Marges minimum : 0.5" (1.27cm) de chaque côté
Espacement entre éléments : ≥ 0.25" (0.64cm)
Espacement ligne (line height) : 1.2-1.5x taille police

Whitespace ≠ Espace perdu
Whitespace = Respiration visuelle = Clarté cognitive
```

## ⚡ Decision Trees Ultra-Rapides

### "Combien de slides ?"
```
Présentation 10 min → 10-15 slides
Présentation 20 min → 20-30 slides
Présentation 45 min → 40-50 slides
+ slides de pratique/feedback
```

### "Combien de texte ?"
```
Titre : 1 phrase (5-10 mots)
Corps : 3-5 keywords MAX
Détails : Dans notes du présentateur
```

### "Quelle image ?"
```
Pertinente au contenu ? → Garder
Belle mais décorative ? → Supprimer
Distracting ? → Supprimer
Basse qualité ? → Remplacer
```

## 📞 Aide Rapide

**Slide trop chargé ?**
→ Chunker en 3 slides

**Audience lit au lieu d'écouter ?**
→ Texte → Notes + Visuel sur slide

**Design plat/ennuyeux ?**
→ Ajouter contraste (size, color, weight)

**Diagramme trop complexe ?**
→ Progressive disclosure (5 clicks)

**Graphique confus ?**
→ Simplifier à 1-3 variables clés
