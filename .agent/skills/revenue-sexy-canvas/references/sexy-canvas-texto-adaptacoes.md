# Adaptações que preservam o sentido — texto

Todo padrão é `[derivado]`. Cada troca passa pela checagem de sentido (fato, promessa, tom). Os exemplos são curtos e fictícios, para ilustrar o gesto, não para copiar.

| Padrão | O que faz | Item que ganha | Exemplo antes → depois | Cuidado |
|---|---|---|---|---|
| Benefício primeiro | Move o resultado para a primeira frase | Preguiça | "Nosso sistema reúne seus dados em um só lugar e ..." → "Seus dados em um só lugar, em 5 minutos. Veja como..." | O prazo precisa ser verdadeiro |
| Número concreto | Troca adjetivo por dado | Ganância, Segurança | "Economize bastante" → "Economize R$ 180 por mês" | O número tem fonte |
| Nomear o atrito | Troca abstração pelo problema que irrita | Ira (inimigo comum), Pertencimento | "Gestão de tarefas" → "Chega de planilha perdida" | Inimigo é situação, não pessoas |
| Promessa parcial | Retém um detalhe para o próximo trecho | Curiosidade | "Veja o passo a passo completo" → "O terceiro passo é o que quase todo mundo erra" | Entregar o detalhe depois |
| Prova antes da promessa | Abre com um fato verificável | Segurança | "Somos a melhor opção" → "Mais de 300 clientes usam; a média de entrega é 24h" | Dado verdadeiro e atual |
| Trocar "tem que" por escolha | Dá autonomia | Liberdade | "Você deve preencher o formulário" → "Você escolhe: formulário ou conversa por mensagem" | Opção precisa existir |
| Linguagem de grupo | Marca quem é "nós" | Pertencimento | "Nossos clientes" → "A gente que atende..." | Gíria do público real |
| Retorno depois da ação | Fecha o ciclo com um aviso | Vaidade, Amor | (sem aviso) → "Seu apoio ajudou a ..." | Afirmação verdadeira (ver exemplo do banco de sangue, T1) |
| Recompensa conquistada | Liga o bônus a uma ação | Recompensa | "Ganhe um brinde" → "Complete o desafio e ganhe um brinde" | Esforço proporcional |
| Pitada de humor | Quebra a formalidade | Diversão | "Comunicado importante" → "Aviso sério, com uma boa notícia no fim" | Tom da marca e contexto (luto, saúde, governo) |
| Comparar com referência | Mostra onde o público quer chegar | Inveja (referência), Vaidade | "Resultados excelentes" → "Quem aplicou saiu de X para Y" | Resultado real e citável |

## Quando não adaptar
- A troca muda o fato ou a promessa.
- O item não passa o teste de apelo (ver `../../revenue-sexy-canvas/references/03-protocolo-consultivo.md`).
- O contexto pede neutralidade (aviso legal, luto, saúde, comunicado oficial); nesses casos, agir só com Segurança e Preguiça.

## Registro na calibração
Se o usuário recusar uma troca ou preferir outra, registrar em `../../revenue-sexy-canvas/references/11-calibracao-v1.md` (nova versão `-vN` quando mudar a régua).
