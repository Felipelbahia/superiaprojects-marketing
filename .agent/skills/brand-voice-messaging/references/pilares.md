# Pilares de conteúdo

Pilar = ângulo + dor + prova. Tema amplo ("educação", "bastidores") não é pilar.

> **Não confundir com pilar de SEO.** Em `conteudo-estrategia/references/content-pillars.md`, "pilar" é a página-pilar com conteúdos satélite (modelo pilar-cluster). Aqui é o pilar **de marca**. Os dois podem se combinar: o pilar de marca define o ângulo; o pilar-cluster organiza as páginas.

## Perguntas ao usuário (chat)

1. Dos candidatos, quais 3 a 5 vocês conseguem sustentar por 6 meses com prova real?
2. Para cada um (ABCDE de formato dominante): A. explicativo B. opinião C. caso/história D. bastidor E. outro.
3. Que prova existe? (dado próprio, caso, demonstração, acesso)
4. Qual é a série recorrente que vira hábito do público (ritual)?
5. O que **não** vira conteúdo mesmo sendo popular?

## Verificação com Sexy Canvas (opcional, na etapa 5)

Cada pilar pode ser lido pelo `revenue-sexy-canvas` para ver qual desejo ele ativa. Isso não altera o pilar aqui; entra em `05-desejo.md`.

## Critério de saída

3 a 5 pilares, cada um com dor, ativo, ângulo, formatos, prova e uma pauta de exemplo; lista do que fica fora.
