# Pré-preenchimento a partir de etapas aprovadas

Antes de perguntar, montar um rascunho com tags `[derivado]` e mostrar ao usuário. Ele corrige em vez de começar do zero.

| Campo de voz | Deriva de | Como |
|---|---|---|
| Traços candidatos | arquétipo (02) | traduzir o arquétipo em 3 traços de fala. Ex.: Sábio -> preciso, paciente, explica o porquê |
| Escalas iniciais | arquétipo + personas | propor um número por eixo e pedir correção |
| "Não comunicar" | credo e inimigo (01), não-crente, limites de território (02) | cada crença com custo vira uma proibição; cada limite vira item |
| Vocabulário preferido | palavras sagradas (01), vocabulário das personas (03) | mantém o termo como a persona o diz |
| Vocabulário banido | termos do concorrente (02), clichês de IA (CLAUDE.md 1.3) | |
| Pilares candidatos | dores das personas (03) x ativos da essência (01) | cada cruzamento relevante é um pilar candidato |
| Voz por contexto | rituais (01), canais das personas (03) | |

Se a etapa de origem ainda tem lacuna, o campo derivado nasce como pergunta e não como afirmação.

Regra de integridade: nunca derivar de modo que contradiga um arquivo existente da marca. Se contradiz, listar a divergência ao usuário antes de seguir.
