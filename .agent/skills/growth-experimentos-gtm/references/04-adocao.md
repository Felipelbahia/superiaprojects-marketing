# Adoção — 55 experimentos B2B

Formato: **N. Título** — Hipótese. Métrica. Benchmark/fonte.

Definição: estágio em que cliente já pago aprofunda uso. Distinto de Ativação (que termina no aha moment) — Adoção mede expansão de uso (mais features, mais users, mais use cases) dentro da conta.

---

## Health scoring

**1. Health score com 4-5 inputs (login + features + tickets + NPS)** — Score automatizado prediz risco/expansão. NRR, expansion rate. Benchmarkit: +6-12 pts NRR em mid-market.

**2. Health score em 3 níveis (verde/amarelo/vermelho) com playbooks** — Cada cor dispara playbook automatizado. Time-to-intervene. Standard CS practice.

**3. Health score por user persona dentro da conta** — Score do champion vs admin vs user. Champion churn alert. Modern CS data ops.

**4. Predictive churn ML model** — ML em product usage + sentiment. Churn prevention. Benchmarkit B2B SaaS.

## QBR / Strategic touchpoints

**5. QBR estruturada trimestral com agenda fixa** — Reunião trimestral com C-suite. Expansion ARR. SerpSculpt 2025: +33% expansion via QBR.

**6. QBR digital assíncrono (vídeo + dashboard)** — Para SMB sem capacidade de QBR ao vivo. Engagement, retention. Modern alternative for low-touch.

**7. Annual roadmap session com cliente** — Antes da renovação, sessão de roadmap conjunta. Renewal rate. Enterprise CS.

**8. Executive sponsor program** — Cada Tier 1 tem exec sponsor da sua empresa. Deal expansion, Tier 1 retention. Enterprise standard.

**9. Customer Advisory Board (CAB)** — 8-12 customers em board strategic input + advocacy. Product-market fit signal, retention. Enterprise CS.

## Feature adoption

**10. Tour de features secundárias (D14, D30, D60)** — 3 touches estruturados pós-onboarding para expandir uso. Feature adoption. Modern PLG pattern.

**11. Tooltips contextuais para feature nova** — In-app message quando feature relevante é detectada. Feature adoption. Pendo/Userpilot standard.

**12. Customer marketing event-driven** — Disparar campanha quando cliente atinge milestone (ex: 100 transações). Upsell rate. Inflection 2025: Sendoso +25% NRR.

**13. Persona-based feature recommendations** — Recomendar features baseado em papel do user. Cross-feature adoption. Notion/Slack patterns.

**14. "Did you know?" weekly email** — Newsletter de power features. Feature adoption MoM. Modern lifecycle.

**15. Vídeo curto in-app (Wistia/Loom embedded)** — 60s tutorial dentro do produto. Feature adoption. Pendo guides.

**16. Certification program (free tier)** — Curso gratuito + certificado com badge LinkedIn. Engagement, advocacy. HubSpot Academy pattern.

**17. Office hours semanal aberta** — Q&A weekly para clientes. NPS, feature adoption. Modern CS pattern.

## Behavior triggers

**18. Trigger de upgrade em 80% de uso do tier** — Notificar quando uso atinge 80% do limite do plano. Upgrade rate, NRR. Optifai 2026.

**19. Trigger de "feature parado" (last used 30d ago)** — Detectar feature core deixou de ser usada → email/CSM. Re-engagement. Mixpanel/Amplitude.

**20. Trigger de power-user emergente** — Detectar user que cresceu uso 3x num mês → outreach do CSM para entender use case. Expansion opportunities found. RevOps pattern.

**21. Trigger de novo user adicionado à conta** — Welcome onboarding personalizado para new seat. Multi-seat ativação. Pendo pattern.

**22. Trigger de C-level que fez login** — Alert para CSM quando exec da conta acessa produto. Strategic engagement. Enterprise CS.

## Community / advocacy

**23. Customer Slack/Discord community** — Espaço dedicado para usuários trocarem práticas. Retention, advocacy. Reforge community model.

**24. User group por região/vertical** — Meetups locais ou virtuais. Community engagement. Enterprise CS pattern.

**25. Power user spotlight mensal** — Featuring user no blog/social com case. Advocacy, retention. Modern customer marketing.

**26. Champion network program** — Tier de "champions" com acesso antecipado a features + invites. Champion retention, NPS. Enterprise.

**27. Customer hackathon / build day** — Evento onde clientes constroem usando seu produto. Deep adoption, advocacy. Notion/Webflow patterns.

## Education / content

**28. Email course "mastery" 5-step** — Sequência de 5 emails ao longo de 30d sobre uso avançado. Feature adoption. Lifecycle B2B.

**29. Live workshop mensal** — 60min hands-on sobre tópico específico. Engagement, NPS. Modern CS.

**30. On-demand learning library** — Biblioteca de vídeos + docs por skill level. Self-serve learning hours. Modern CS.

**31. Knowledge base com search inteligente** — Help docs + AI search. Tickets/NPS. Intercom/Notion AI pattern.

**32. Personal CSM video update mensal** — CSM grava 2-min Loom para sua conta com updates. Engagement, retention. Tier 1/2 pattern.

**33. Customer playbook por use case** — "Como [Customer X] resolveu [problema] com a gente" templates. Use case adoption. Customer marketing.

## Product-led adoption

**34. Empty state direcionando para próxima feature** — Quando user "esgota" feature primária, sugerir próxima. Feature adoption. Pattern em todos PLG products.

**35. Notifications inteligentes (não spam)** — Notification engine que prioriza por relevância. Engagement, opt-out rate. Mixpanel pattern.

**36. Habit reinforcement loops** — Aviso de inatividade (ex: "você não usou X em 7 dias"). Re-engagement. Reforge habit framework.

**37. Daily/Weekly digest via email/Slack** — Resumo personalizado da atividade. DAU/WAU. Linear/Notion pattern.

## Account expansion signals

**38. Multi-team detection** — Detectar quando 2ª equipe da conta começa a usar. Cross-team expansion. PLG enterprise pattern.

**39. Geographic/BU expansion detection** — Detectar quando users de outra geografia/BU criam contas. Account expansion alert. Enterprise CS data.

**40. Integration adoption tracking** — Conta que conecta 3+ integrações tem 5x mais retention. NRR por integration count. Reforge data.

**41. API usage tracking** — Volume crescente de API = sinal de adoção profunda. NRR predictor. Modern PLG.

## CSM playbooks

**42. Onboarding playbook 90d com milestones** — 30/60/90d milestones definidos por papel. Time-to-value. Enterprise CS standard.

**43. Quarterly success metric review** — Revisão trimestral do customer success metric (definido com cliente no kickoff). Renewal rate. Modern CS.

**44. Customer maturity model (5 níveis)** — Score onde a conta está no journey. Predictable upgrade path. Enterprise CS.

**45. NPS survey trigger por evento (não calendário)** — Survey após evento crítico (renewal, upgrade, sucesso). NPS quality, response rate. Inflection pattern.

## AI-powered customer success

**46. AI predictive churn ML model** — Modelo prevendo churn em 60-90d baseado em product usage + sentiment + tickets. Churn prevention rate. Benchmarkit 2026.

**47. AI-generated weekly customer digest** — AI cria resumo personalizado da atividade do cliente para CSM enviar. Engagement, NPS. Modern CS 2026.

**48. AI conversation summary post-meeting (Avoma/Gong)** — Toda call de CS resumida + action items extraídos. Time saved/CSM. Standard 2026.

**49. AI champion identification** — ML identifica champion real (não só admin) baseado em engagement profundo. Champion turnover detection. Enterprise CS 2026.

**50. AI-powered QBR auto-prep** — AI prepara deck QBR com métricas + recomendações + call transcripts. Prep time (-70%). Modern CS 2026.

**51. AI-driven feature recommendation engine** — In-product que sugere próxima feature por papel + uso. Feature adoption. AI-native PLG 2026.

**52. Automated Slack alert por sinal de risco** — Alert real-time para CSM quando login drop ou ticket spike. Time-to-intervene. Modern RevOps.

**53. AI-generated success report personalizado** — PDF custom para Tier A/B com ROI quantificado pela AI. Renewal advocacy. Enterprise CS 2026.

**54. AI competitive intel sobre o cliente** — Monitor sinais de que o cliente avalia concorrente. Save rate. Modern CS data ops.

**55. Customer-facing AI assistant in-product** — Chatbot trained em docs + uso pessoal do cliente. Tickets reduzidos, NPS. Intercom/Notion AI 2026.
