# Marketing Campaign Execution (workflow)

Este workflow é só a porta de entrada. O conteúdo completo, com as rotas para as skills especialistas de cada frente, o checklist de validação e o protocolo de desbloqueio, fica numa fonte única: a skill [revenue-campanhas](../skills/revenue-campanhas/SKILL.md).

## Como usar

1. Abra a skill [revenue-campanhas](../skills/revenue-campanhas/SKILL.md).
2. Identifique a frente do pedido na tabela **Rotas por especialidade** e abra a skill especialista indicada.
3. Antes de lançar, percorra o **Campaign Validation Checklist** da skill.
4. Se a campanha estiver parada, use o **When Stuck Protocol**.
