# Content Brief Generator (workflow)

Este workflow é só a porta de entrada do comando `/content-brief-generator`. O conteúdo completo, mantido e atualizado, fica numa fonte única: a skill [conteudo-briefing](../skills/conteudo-briefing/SKILL.md).

## Como usar

1. Leia e siga a skill [conteudo-briefing](../skills/conteudo-briefing/SKILL.md) (caminho: `.agent/skills/conteudo-briefing/SKILL.md`).
2. Abra as referências da skill apenas quando o `SKILL.md` indicar.

> A versão anterior deste workflow está guardada em `.agent/skills/_arquivo/mescladas/workflows-originais/content-brief-generator.md`.
