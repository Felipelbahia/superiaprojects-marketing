# PRD Generator (workflow)

Este workflow é só a porta de entrada do comando `/prd-generator`. O conteúdo completo, mantido e atualizado, fica numa fonte única: a skill [produto-prd](../skills/produto-prd/SKILL.md).

## Como usar

1. Leia e siga a skill [produto-prd](../skills/produto-prd/SKILL.md) (caminho: `.agent/skills/produto-prd/SKILL.md`).
2. Abra as referências da skill apenas quando o `SKILL.md` indicar.

> A versão anterior deste workflow está guardada em `.agent/skills/_arquivo/mescladas/workflows-originais/prd-generator.md`.
